[取得する情報と利用目的]

本アプリは、Google の広告サービス「AdMob」によって収益化しています。広告の配信のため、AdMob の広告 SDK が次の情報を自動的に取得し、Google に送信します。本アプリ自体が、氏名・住所・電話番号などの個人を特定する情報を取得することはありません。

取得する情報 内容
おおよその位置情報 端末の IP アドレス (大まかな地域の推定に使われます)
アプリの操作 アプリの起動、タップ、広告の表示や視聴などの操作
診断情報 アプリや広告 SDK の動作に関する情報 (起動時間、応答状況など)
識別子 広告 ID、アプリセット ID などの端末の識別子

これらの情報は、広告の配信、効果の測定・分析、不正行為の防止とセキュリティの確保のために利用されます。送信は暗号化された通信 (TLS) で行われます。

[第三者への提供]

上記の情報は、広告の配信のために Google に送信され、Google のプライバシーポリシーおよび広告ポリシーに従って取り扱われます。本アプリの開発者が、これ以外の第三者に情報を提供することはありません。

Google による情報の利用について: https://policies.google.com/technologies/ads?hl=ja

[広告 ID について]

広告のパーソナライズに使われる広告 ID は、端末の設定からいつでもリセット・削除できます。

  • Android: 設定 → Google → 広告
  • iOS: 設定 → プライバシーとセキュリティ → トラッキング
